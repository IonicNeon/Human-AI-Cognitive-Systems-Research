# Code of Conduct

This repository exists for serious inquiry, criticism, replication, and constructive disagreement.

Participants must critique evidence/methods/claims rather than attack people; avoid harassment, threats, doxxing, or publication of private information; respect participant consent and ethics boundaries; avoid fabricated evidence or falsified provenance; and distinguish strong disagreement from misconduct.

Good-faith methodological criticism is welcome even when severe. Civility does not require consensus.

Security or privacy vulnerabilities should be reported privately. See `SECURITY.md`.
