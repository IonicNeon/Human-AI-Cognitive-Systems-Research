# Public release checklist

- [ ] Artifact is beneficial/necessary to the public research record.
- [ ] Release class is `PUBLIC-APPROVED`.
- [ ] No credentials, tokens, secrets, private URLs, or hidden keys.
- [ ] No unnecessary personal/third-party identifying information.
- [ ] Ethics/consent scope permits release.
- [ ] Copyright/licensing permits redistribution.
- [ ] No held-out material is disclosed in a way that contaminates active research.
- [ ] Raw private data were never staged in the public repository.
- [ ] Claims are labeled at their actual evidence maturity.
- [ ] Data/analysis versions are identified.
- [ ] Public provenance is sufficient to audit released claims.
- [ ] Study status is current.
- [ ] New lineage relationships are registered.
- [ ] Release notes include limitations and unresolved dependencies.

When uncertain, do not publish; derive a safer artifact or keep the source private.
