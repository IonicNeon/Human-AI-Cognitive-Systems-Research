# Evidence and claim taxonomy

## Dependency labels

- `FIXED`
- `PROVISIONAL`
- `PENDING-CORPUS`
- `PENDING-ADJUDICATION`
- `PENDING-EXPERIMENT`
- `SIMULATED-ONLY`

## Result classes

- `CURRENT-BOUNDED-RESULT`
- `PROVISIONAL-INTERPRETATION`
- `CONFIRMATORY-RESULT`
- `EXPLORATORY-RESULT`
- `NONEMPIRICAL-METHOD`

A claim may mature only as far as its weakest unresolved dependency permits.

Quantitative values that can change with corpus completion, adjudication, or prospective testing should be generated from versioned data rather than manually copied into prose where practical.
