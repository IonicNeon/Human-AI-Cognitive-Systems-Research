# Research lifecycle

```text
spawn → triage → prespecify → collect → adjudicate → analyze → write
      → adversarial review → public-safe derivation → release → spawn
```

- **Spawn:** question/anomaly/contradiction/failure/result/imported idea creates a candidate branch.
- **Triage:** determine whether it is materially distinct and warrants permanent identity.
- **Prespecify:** freeze questions, hypotheses, inclusion rules, metrics, scoring, cutoffs, and planned analysis when appropriate.
- **Collect:** acquire evidence while preserving provenance/privacy.
- **Adjudicate:** apply frozen coding/inclusion rules; record ambiguity.
- **Analyze:** run versioned analysis; distinguish confirmatory from exploratory.
- **Write:** manuscripts summarize governed state, not replace it.
- **Adversarial review:** seek alternative explanations, leakage, overclaiming, selection effects, coding error, and reproducibility failure.
- **Public-safe derivation:** expose the minimum sanitized evidence needed to audit public claims.
- **Release:** publish versioned outputs.
- **Spawn again:** materially distinct new questions get new IF-R identities.
