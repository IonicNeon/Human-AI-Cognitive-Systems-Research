# Lineage relation vocabulary

- `spawned-by` — target question materially arose from parent activity/observation.
- `derived-from` — materially transformed from parent material.
- `extends` — broadens/deepens parent scope.
- `tests` — evaluates a parent claim/mechanism/prediction.
- `replicates` — attempts reproduction under comparable conditions.
- `attempts-to-falsify` — designed primarily to expose failure conditions.
- `challenges` — disputes assumption, method, interpretation, or result.
- `operationalizes` — turns a concept into measurable definition/instrument/experiment.
- `uses-method-from` — inherits a method without implying conceptual descent.
- `uses-data-from` — reuses data/evidence.
- `generalizes` — tests extension to a new population/environment/task/domain.
- `compares-with` — structured comparison without directional descent.
- `supersedes` — intentionally replaces earlier object/method while preserving history.
- `inspired-by` — conceptual influence exists but stronger operational lineage is not established.
