# IF-R001 — Birth and Emergence

## Functional reframing proposed 2026-10-18

The historical "birth" should be reconstructed as the first supported availability of distinct functions—durable capture, canonical state, source provenance, retrieval, continuity, correction, coordination, and recovery—rather than a single repository event or a rhetorical first use of "second brain." Date proposal, implementation, executed fixture, and observed real-task use separately. A functioning file hierarchy does not establish a functioning memory assistant. Compare capability *definitions* with contemporaneous systems and published literature, but reserve numeric performance claims for IF-R003. The proposed cross-paper protocol is [here](../../docs/FUNCTIONAL-CAPABILITY-BENCHMARK-PROTOCOL.md). Existing source-boundary and public-release gates remain in force.
